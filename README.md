# BpmnCraft / هم‌نگار فرآیند 🚀
> **سامانه پیشرفته مدلسازی، بازبینی و مدیریت چرخه حیات فرآیندهای کسب و کار (BPMN 2.0)**

سامانه **BpmnCraft (هم‌نگار فرآیند)** یک پلتفرم تحت وب جامع جهت طراحی، مستندسازی، بازبینی گروهی و نسخه‌گذاری فرآیندهای کسب‌وکار بر اساس استاندارد بین‌المللی **BPMN 2.0** است. این برنامه با معماری ماژولار و مبتنی بر اصول **SOLID** طراحی شده و قابلیت کار به صورت آنلاین/آفلایت با ذخیره‌سازی محلی (Local Persistence) و مدیریت تیم‌ها را فراهم می‌سازد.

---

## 🌟 ویژگی‌های کلیدی سیستم (Key Features)

1. **طراحی و مدلسازی کامل BPMN 2.0**:
   - پشتیبانی از تمامی المان‌های استاندارد (رویدادهای شروع/پایان/میانی، فعالیت‌ها، درگاه‌های تصمیمی، استخرها/Pool و مسیرها/Lane)
   - پنل ویژگی‌ها (Properties Panel)، ابزار رنگ‌آمیزی المان‌ها و نقشه کوچک (Minimap)
   - پالت سفارشی‌سازی‌شده فارسی/انگلیسی و Context Pad پیشرفته

2. **مدیریت پنل کاربری و احراز هویت (Authentication)**:
   - فرم ورود و ثبت‌نام با نام کاربری و کلمه عبور
   - امکان سوئیچ سریع بین حساب‌های کاربردی پیش‌فرض
   - ذخیره‌سازی امن حالت کاربر در `localStorage`

3. **همکاری تیمی و مدیریت دسترسی (RBAC - Role Based Access Control)**:
   - تعریف تیم‌های کاری و واحدهای سازمانی مختلف
   - تخصیص نقش‌های ۴ گانه:
     - 👑 **مدیر تیم (Manager)**: دسترسی کامل به ایجاد فرآیند، مدیریت اعضا، تعیین نقش‌ها و حذف
     - ✏️ **ویرایش‌گر (Editor)**: طراحی و ذخیره نسخه‌های جدید فرآیند
     - 🔍 **بازبینی‌کننده (Reviewer)**: بررسی و تغییر وضعیت فرآیند (تایید شده / نیازمند اصلاح)
     - 👁️ **مشاهده‌کننده (Viewer)**: مشاهده فقط‌خواندنی دیاگرام‌ها و ثبت نظرات
   - امکان اضافه کردن اعضای جدید بر اساس ایمیل

4. **ساختار درختی و پوشه‌بندی چندسطحی (Multi-Level Folder Tree)**:
   - ایجاد، تغییر نام، حذف و انتقال پوشه‌ها تا سطح دلخواه
   - انتقال فرآیندها بین پوشه‌ها با ابزار Move Modal
   - مسیر نان‌سوخاری (Breadcrumb) جهت پیمایش آسان

5. **چرخه حیات فرآیند و نسخه‌گذاری (Versioning & Life Cycle)**:
   - ثبت نسخه جدید به همراه خلاصه تغییرات (Change Summary)
   - کشوی جانبی تاریخچه نسخه‌ها و امکان بازگردانی (Restore) به نسخه‌های قبلی
   - ابزار **Visual Diff**: مقایسه بصری و متنی دو نسخه مختلف فرآیند با هایلایت رنگی المان‌های افزوده‌شده/تغییریافته/حذف‌شده

6. **ممیزی هوشمند و شبیه‌سازی (Linting & Token Simulation)**:
   - موتور ممیزی بر اساس قواعد `bpmnlint` جهت شناسایی خطاهای مدلسازی (مانند رویدادهای بدون جریان یا درگاه‌های معلق)
   - شبیه‌سازی حرکت توکن‌ها (Token Simulation) در طول مسیرهای فرآیند

7. **ارزیابی و ثبت نظرات (Review Comments Drawer)**:
   - ثبت نظرات ممیزان و ذینفعان روی کل فرآیند یا المان‌های خاص
   - علامت‌گذاری نظرات به عنوان حل‌شده (Resolved)

8. **خروجی‌های متنوع و اشتراک‌گذاری عمومی (Export & Embed)**:
   - خروجی‌های BPMN 2.0 XML, SVG, PNG و PDF با کیفیت بالا
   - لینک اختصاصی تعبیه فرآیند (`/view/:processId`) جهت قرار دادن بوم فقط‌خواندنی در سایر سامانه‌ها

## 🏗️ معماری نرم‌افزار و اصول SOLID

سورس‌کد پروژه با پایبندی کامل به اصول **SOLID** بازنگری و تمیزکاری شده است:

- **Single Responsibility Principle (SRP)**:
  - هر کامپوننت مسئولیت منحصربه‌فردی دارد؛ برای نمونه `DiagramMetadataHeader` فقط نوار ابزار متادیتا را مدیریت می‌کند، `CommentsDrawer` نظرات را و `FolderTree` ساختار درختی پوشه‌ها را.
- **Open/Closed Principle (OCP)**:
  - سیستم ارائه لایه‌ها و مدیریت حالت به گونه‌ای طراحی شده که اضافه کردن ویژگی‌های جدید (مانند اتصال به دیتابیس Firebase یا Cloud SQL) بدون دستکاری کامپوننت‌های UI امکان‌پذیر است.
- **Liskov Substitution Principle (LSP)**:
  - تمامی اینترفیس‌ها و تایپ‌های تعریف‌شده در `types.ts` رفتار یکنواختی دارند.
- **Interface Segregation Principle (ISP)**:
  - Propهای کامپوننت‌ها تفکیک شده و از ارسال اضافی داده‌های غیرمرتبط جلوگیری شده است.
- **Dependency Inversion Principle (DIP)**:
  - کامپوننت‌ها به جای اتکا مستقیم به داده‌های سخت‌کدشده، از هوک مرکزی `useWorkspace()` جهت دریافت متدها و stateها استفاده می‌کنند.

## 📁 ساختار پروژه (Directory Structure)

```text
src/
├── components/                  # کامپوننت‌های رابط کاربری
│   ├── AuthModal.tsx            # پنجره ورود، ثبت‌نام و مدیریت حساب
│   ├── BpmnModelerApp.tsx       # بوم اصلی مدلسازی bpmn-js و نوار ابزارها
│   ├── CommentsDrawer.tsx       # کشوی نظرات و ارزیابی فرآیند
│   ├── CreateDiagramModal.tsx   # دیالوگ ساخت فرآیند جدید
│   ├── DiagramCard.tsx          # کارت نمایش فرآیند در داشبورد
│   ├── DiagramMetadataHeader.tsx# نوار بالای بوم طراح
│   ├── DiagramsDashboard.tsx    # داشبورد اصلی مدیریت فرآیندها
│   ├── DiffModal.tsx            # پنجره مقایسه بصری دو نسخه (Visual Diff)
│   ├── EmbedViewer.tsx          # نمایشگر عمومی فرآیند (/view/id)
│   ├── FolderTree.tsx           # درخت پوشه‌بندی چندسطحی
│   ├── MoveModal.tsx            # پنجره جابه‌جایی پوشه‌ها و فرآیندها
│   ├── TeamManagementModal.tsx  # پنجره مدیریت اعضا و دسترسی تیم
│   └── VersionHistoryDrawer.tsx # کشوی تاریخچه نسخه‌ها
├── context/
│   └── WorkspaceContext.tsx     # مدیریت متمرکز حالت فضای کاری، کاربران، تیم‌ها و فرآیندها
├── data/
│   └── initialData.ts           # داده‌های اولیه نمونه (کاربران، تیم‌ها و فرآیند تسویه حساب)
├── lib/
│   ├── CustomContextPadProvider.ts # پالت تعاملی سفارشی روی المان‌ها
│   ├── customTranslate.ts       # ماژول ترجمه اختصاصی منوها به فارسی
│   ├── bpmnlintConfig.ts        # قواعد ممیزی و استانداردسنجی فرآیند
│   ├── packedBpmnlintConfig.js  # باندل شده قواعد ممیزی
│   └── i18n.ts                  # متون دوزبانه (فارسی / انگلیسی)
├── types.ts                     # تعاریف تایپ‌ها و اینترفیس‌های سیستم
├── App.tsx                      # کامپوننت ریشه و مسیریابی
└── main.tsx                     # نقطه ورود React
```

## 💻 راهنمای نصب و اجرا (Installation & Setup)

پیش‌نیازها: داشتن Node.js نسخه 18 یا بالاتر.

```bash
# ۱. کلون کردن مخزن
git clone https://github.com/your-username/bpmn-craft.git
cd bpmn-craft

# ۲. نصب بسته‌ها و وابستگی‌ها
npm install

# ۳. اجرای سرور توسعه
npm run dev
```

برنامه روی آدرس `http://localhost:3000` در دسترس خواهد بود.
